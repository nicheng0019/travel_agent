# 自驾路线规划 Agent

这是一个结合大语言模型与高德地图 API 的自驾路线规划工具。

用户只需要输入起始点和自然语言要求，例如目的地、途经景点、旅行天数、每日驾驶时间上限等，Agent 就会生成逐日自驾行程，并使用高德地图核验每一段路线的实际里程和预计驾驶时间。

程序支持多轮对话。生成第一版路线后，可以继续提出“减少一天”“删除某个景点”“第三天少开车”等修改要求，Agent 会在上一版行程基础上重新规划并再次调用高德地图核验。

## 主要功能

- 根据自然语言要求生成逐日自驾路线。
- 输出总天数、每日起点、终点、途经点和活动安排。
- 使用高德地图计算每段路线的里程、预计时长、收费和主要道路。
- 自动汇总每日里程、每日驾驶时长和全程数据。
- 支持“每天驾驶不超过 N 小时”的硬约束检查。
- 路线超出每日驾驶上限时，自动要求大模型调整住宿点、天数或途经点。
- 支持景区、寺院、酒店等 POI 与同名地点消歧。
- 支持多轮路线微调，并在调整失败时保留上一版有效路线。
- 大模型润色接口暂时不可用时，仍可输出高德地图核验后的结构化行程。

## 工作流程

```text
用户输入起点和要求
        ↓
大模型生成结构化逐日行程
        ↓
高德地图解析地点并逐段规划驾车路线
        ↓
检查每日驾驶时间等约束
        ↓
不满足约束时自动反馈给模型重新规划
        ↓
大模型整理并输出详细行程
        ↓
用户继续输入修改意见，进入下一轮
```

路线中的景点安排和旅行建议由大模型生成；里程和驾驶时间来自高德地图 API。实际出发前仍应使用高德地图客户端确认实时路况、道路封闭、天气和景区开放情况。

## 环境要求

- Python 3.10 或更高版本
- `requests`
- `python-dotenv`
- 智谱开放平台 API Key
- 高德开放平台 Web 服务 API Key

## 配置 API

复制 `.env.example` 为 `.env`：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填写真实配置：

```dotenv
LLM_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
LLM_MODEL=glm-5.3-flash
LLM_API_KEY=你的智谱APIKey
AMAP_KEY=你的高德Web服务APIKey
```

变量说明：

| 变量 | 用途 |
|---|---|
| `LLM_URL` | 大模型 Chat Completions 接口地址 |
| `LLM_MODEL` | 使用的大模型名称 |
| `LLM_API_KEY` | 大模型 API 身份凭证 |
| `AMAP_KEY` | 高德开放平台 Web 服务 Key |

程序始终从 Python 文件所在的项目目录加载 `.env`，因此从其他目录启动时也能找到配置。

## 使用方法

### 1. 交互式启动

在项目目录执行：

```powershell
python.exe travel_agent.py
```

根据提示输入起始点和路线要求：

```text
请输入起始点：兰州
请输入具体要求：设计5天甘南自驾路线，想去拉卜楞寺、扎尕那和郎木寺，每天驾驶不超过5小时，最后返回兰州
```

### 2. 使用命令行参数启动

```powershell
python.exe travel_agent.py `
  --origin "兰州" `
  --requirements "设计5天甘南自驾路线，想去拉卜楞寺、扎尕那和郎木寺，每天驾驶不超过5小时，最后返回兰州"
```


参数说明：

| 参数 | 是否必需 | 说明 |
|---|---|---|
| `--origin` | 否 | 自驾起始地点；未提供时会交互询问 |
| `--requirements` | 否 | 目的地、天数、途经点和驾驶限制；未提供时会交互询问 |

### 3. 多轮微调路线

第一版路线生成后，程序会继续显示：

```text
请微调路线：
```

可以连续输入修改意见，例如：

```text
第三天不去花湖，直接前往扎尕那
```

```text
第四天驾驶时间太长，增加一天并选择合适的中途住宿点
```

```text
保留所有景点，但每天最多驾驶4小时
```

```text
最后不返回起点，终点改为成都
```

每轮修改成功后，新路线会成为下一轮调整的基础。没有被用户要求修改的内容会尽量保留。

如果某轮因为大模型超时、地点无法解析或高德查询失败而未完成，程序会保留上一版路线：

```text
本轮调整失败，已保留上一版路线：错误详情
```

输入以下任意命令结束会话：

```text
完成
退出
exit
quit
q
```

## 输出内容

最终行程通常包含：

- 行程标题、总天数和全程总里程。
- 全程预计驾驶时间。
- 每天的起点、终点和途经点。
- 每一段路线的里程和预计驾驶时长。
- 主要道路和预计收费。
- 每天的游览活动和住宿建议。
- 高原、天气、道路和景区预约提醒。

高德接口返回的驾驶时间是正常交通条件下的估算，不包含游览、休息、用餐、加油、拥堵和临时交通管制时间。


## 常见问题

### 缺少环境变量

如果出现：

```text
缺少环境变量 AMAP_KEY，请在项目 .env 文件中配置
```

或：

```text
缺少环境变量 LLM_API_KEY，请在项目 .env 文件中配置
```

请确认项目目录存在 `.env`，变量名称正确，并且等号后填写了有效值。

### 地点解析失败

尽量输入完整、明确的地点名称。例如使用“阿坝县莲宝叶则石头山景区”，而不是只输入“莲宝叶则”。同名地点较多时，建议附带城市或区县。

程序会优先搜索上一站附近的同名 POI，并比较高德驾车距离，但明确的地点名称仍能显著提高准确度。

### 大模型请求超时

如果首次生成路线时模型请求超时，程序会报告错误，可以稍后重新运行。如果只是在最后的行程润色阶段超时，程序会自动输出高德核验后的本地格式化版本。

### 行程生成较慢

为了避免把景点定位到外省同名地点，程序可能查询多个 POI 候选并比较驾车距离。包含大量景点的行程会产生更多高德 API 请求，通常需要几十秒到数分钟。

### 路线仍有异常

大模型和地图搜索都可能出现误判。遇到明显异常时，可以在多轮对话中输入更明确的修改要求：

```text
甘海子指的是九寨沟县漳扎镇附近的甘海子，请重新规划第一天
```

也可以直接在初始要求中为景点补充所属区县。

## 安全说明

- 不要将 `.env` 提交到 Git 或发送给他人。
- 如果 API Key 曾经公开，应立即到对应平台撤销并重新生成。
- API 调用可能产生费用，请关注智谱与高德平台的配额和计费规则。
- 本项目提供的是行程规划建议，不能代替出发前的实时导航、天气预警和道路安全判断。
